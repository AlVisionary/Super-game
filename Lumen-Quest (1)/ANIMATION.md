# Hero animation asset

Built-in Imagegen created `dist/assets/hero-actions.png` using `dist/assets/heroes.png` as the identity reference. The original collection portraits are retained. The generated PNG was copied unchanged into the project; it has genuine transparency and measures 1086 × 1448 pixels, giving a 6 × 8 grid of 181-pixel square cells.

Rows: Iron Warden, Fern Ranger, Violet Shade, Elder Sage, Astral Weaver, Dawn Keeper, Ember Sovereign, Chrona. Columns: idle, walk A, walk B, run, attack, jump. The renderer selects these poses, flips them for left movement, adds a small stride bob, and uses physics for jumps. Poses are generated interpretations of the supplied designs, not pixel-identical redraws.

Clean detailed pixel art, readable silhouette, consistent scale, ample 20px padding in cells. This is functional animated game artwork, not a poster.
